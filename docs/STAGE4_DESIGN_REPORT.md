## Что реализовано

- Белый фон, тёмно-синий текст `#09122D`, яркий синий акцент `#0055F5`, компактная шапка, тонкие границы и мягкие тени. Системные шрифты Segoe UI / Arial; внешних шрифтов и новых зависимостей нет.
- Store: крупный заголовок с синим акцентом, фотография кружки, три небольших преимущества и карточки товаров. На телефоне карточки горизонтальные; цена и название продолжают поступать с сервера.
- Celebrate: синяя отметка успешной оплаты, сдержанный декоративный фон, купленный товар и три карточки выбора подарка.
- Gift Studio: тёмная рабочая область с настройками слева и большим предпросмотром справа. Тёмное оформление сохранено на телефоне; форма и превью располагаются последовательно. Согласие на фото остаётся отдельным и выключенным по умолчанию. Поле выбора файла имеет локализованное оформление, сохраняя нативный ввод и клавиатурный доступ.
- Result: сохранённое изображение занимает основную часть экрана, рядом — скачивание PNG и краткая информация. На телефоне изображение показано первым. Полный PNG и его брендирование не обрезаются.
- DE/EN, клавиатурный фокус, ссылка пропуска навигации, настройка reduced motion. Навигация к существующим покупкам открывает историю, не заменяя новый заказ старым.
- DEMO обозначен на карточках, в студии и на результате. Один оплаченный заказ по-прежнему даёт один подарок; кнопки повторной генерации на готовом результате нет.

В референсе есть вымышленные стили, варианты портретов, повторная генерация и похожий на официальный знак PayPal. Эти элементы не перенесены. Настоящая кнопка PayPal остаётся компонентом SDK. Мобильная студия сделана тёмной в соответствии с текстовым заданием, хотя в мобильном фрагменте прототипа она светлая.

Фотографии товаров и существующие статические mock-иллюстрации отличаются от изображений в прототипе. Они используются как законные локальные ресурсы; портреты из референса не извлекались. Авторы и лицензии перечислены в [ASSET_CREDITS.md](ASSET_CREDITS.md). Платные генераторы и OpenAI не использовались.

## Проверки

| Проверка | Результат |
| --- | --- |
| `npm.cmd run typecheck` | PASS: Vue + server TypeScript |
| `npm.cmd run build` | PASS: `client/dist/`, `server/dist/index.js` |
| `npm.cmd test` | 65/65 серверных тестов |
| `npm.cmd run test:smoke` | 4/4 сценария, TAP 5/5 с родительским тестом |
| `npm.cmd run test:browser` | 37/37 сценариев Chrome, TAP 38/38 с родительским тестом |
| Настоящий PayPal SDK v6 | Кнопка видима и доступна на 375/768/1440 px в DE/EN; 0 заказов, 0 платёжных вызовов, 0 AI-вызовов, 0 ошибок страницы |
| Адаптивность | Все четыре экрана и три формы на 375/768/1440 px в DE/EN, без горизонтальной прокрутки и перекрытия названий/цен описаниями |
| Правила подарков | Три последовательные тестовые покупки, разные режимы, просмотр старых результатов, reload, скачивание и защита от повторной выдачи |
| Совместимость | Старые PNG без брендирования открываются и скачиваются без изменения байтов; DE/EN-футер новых PNG сохранён |
| Секреты | Проверены изменённые/новые файлы и frontend bundle; значения ключей из `.env` и приватные ключи не обнаружены |

Браузерный набор также проверяет ошибки и отмену Checkout, восстановление незавершённой покупки, consent/withdrawal, удаление метаданных, ошибки генерации и восстановление результата после потери ответа. Автоматические платежи выполняются только через изолированный имитатор. Серверные тесты подтверждают сохранность правил выдачи и обработку параллельных запросов.

В первом прогоне новые раскрываемые блоки потребовали обновить ожидания тестов и снимать только видимые изображения. Это исправлено. При визуальной проверке устранено отображение системного текста выбора файла на языке Windows. Финальные проверки выполнялись после этих изменений.

Backend, SQLite, API, `client/src/paypal.ts`, зависимости и deployment-файлы не менялись. Существующие покупки и подарки не удалялись. Режим остаётся `AI_PROVIDER=mock`.

Изменения подготовлены в ветке `main` от базового коммита `255a0ee9d60cf261e85885ec00a0eadd05ae99af`. Перед публикацией повторно выполняются typecheck, build, серверные, smoke- и браузерные тесты, а также проверка содержимого коммита. `.env`, SQLite, `access.txt`, приватная инфраструктурная передача и временные журналы исключены из Git. Deployment не выполняется.

Локальный просмотр: `npm.cmd run dev:server` и `npm.cmd run dev:client` в двух консолях, затем `http://localhost:5173`. Галерея `docs/design-review.html` открывается непосредственно как локальный файл, без новой оплаты.
