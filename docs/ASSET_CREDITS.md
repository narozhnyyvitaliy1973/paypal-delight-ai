The photo licenses permit free website use and modification. The images are not resold as stock or represented as original photography by this project. Visually checked for visible third-party logos before inclusion. An initially considered branded tote photo was rejected and is not shipped.

All images are served locally. Sharp, already installed in the project, was used for resizing and WebP conversion without preserving EXIF. No external image/CDN/font requests at runtime, no AI image calls, and no new dependency. SVG icons and favicon are simple project-authored geometry, not a PayPal logo. Typography uses the system Segoe UI / Arial stack.

Public demo thumbnails contain no customer data. Actual gift previews and downloads continue to use the existing protected API and branded PNG; frontend thumbnails never replace saved customer results.

The user supplied `docs/design-reference/ui-concept.png` as the approved UI composition reference on 26 October 2026. It is included in the local design review for comparison. Portraits, logos and other artwork from that montage are not extracted into application assets. The application retains the existing demo illustrations and uses its own sparkle symbol instead of the depicted PayPal-style logo.
