# Этап 3A — локализация и подготовка mock-подарков

Дата: 24 октября 2026, Europe/Berlin.

## Реализовано

- `vue-i18n`: DE/EN, определение языка браузера, fallback EN, ручной переключатель,
  сохранение выбора в localStorage и обновление атрибута `html.lang`.
- Переведены магазин, серверные названия/описания товаров, checkout, Celebrate,
  подсказки, ошибки и статусы. Цены и идентификаторы по-прежнему задаёт сервер.
  Ошибки переводятся по кодам, поэтому уже показанное сообщение меняет язык сразу.
- Подготовлены переводы будущих полей пожеланий, языка и необязательного фото.
- Страницы `/legal` и `/privacy` с DE/EN, доступные из footer и по прямым ссылкам.
  Данные владельца, правовые основания, сроки хранения и провайдерские соглашения
  явно оставлены для заполнения и проверки перед публичным deployment.
- На юридических страницах нет PayPal SDK. Внешние Google Fonts удалены, используются
  системные шрифты. Юридический текст различает текущую локальную демо-обработку
  и будущие Hetzner/OpenAI/upload-сценарии.
- Серверный интерфейс провайдера и `AI_PROVIDER=mock` без ключей. `openai` приводит
  к явной ошибке запуска, а не к сетевому вызову или скрытой подмене.
- Один локальный PNG-образец Caricature с маркировкой DEMO. Сервер возвращает единый
  `GiftResult` с `isDemo`, PNG-байтами и метаданными. Образец не персонализируется.
- Подготовлен отдельный фото-компонент без сетевой отправки. Согласие по умолчанию
  выключено, отказ очищает файл. Компонент пока не подключён к покупке.
- Серверный photo helper: согласие, лимиты 5 MiB / 16 MP, JPEG/PNG/WebP по содержимому,
  запрет анимации, пере-кодирование без EXIF/XMP/IPTC/ICC, применение ориентации,
  удаление временной очищенной копии после успешной обработки и исключений.
  Оригинал не хранится на диске. Очистка после принудительного завершения процесса
  должна быть завершена при подключении реального upload; сейчас такого endpoint нет.

## Проверки

| Проверка | Результат |
| --- | --- |
| Typecheck | Успешно |
| Build | Успешно: client/dist, server/dist/index.js и server/dist/assets |
| Серверные тесты | 45/45 |
| Smoke | 4/4 сценария, TAP 5/5 с родительским тестом |
| Browser | 16/16 сценариев, TAP 17/17 с родительским тестом |
| Настоящий PayPal SDK v6 | HTTP 200, настоящая кнопка видна, ошибок страницы нет; без нажатия/оплаты |

Браузерные тесты используют настоящий Chrome, Vue, Fastify и SQLite с имитацией
PayPal. Проверены EN/DE, fallback, сохранение языка, Celebrate, отмена/отказ/PENDING,
ошибки SDK/backend, возврат с юридических страниц без повторной покупки, сохранение
платёжного сценария, мобильная вёрстка и отдельный фото-компонент. Реальная повторная
оплата не выполнялась. Mock проверен с запрещённым `fetch`; обращения к AI отсутствуют.

Проверки фото включают согласие, поддельный MIME, SVG под видом PNG, повреждённые,
пустые, слишком большие и анимированные файлы; метаданные удаляются во всех трёх
разрешённых форматах. Временные файлы удаляются и при исключении callback.

и погашение права не реализованы. Кнопки трёх подарков остаются неактивными. Нет новых
сервисов, миграции SQLite, изменений production-инфраструктуры, AI-расходов или deployment.
