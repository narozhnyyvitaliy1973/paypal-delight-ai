# Stage 5 — Cloudflare Workers AI

Дата: 27 октября 2026. База изменений: `931d85a`.

## Реализовано

Существующий интерфейс `GiftProvider` поддерживает `mock` и `cloudflare`.
По умолчанию остаются `AI_PROVIDER=mock` и `AI_ENABLED=false`.
OpenAI не реализован. Настоящие Cloudflare API-вызовы, платежи, deployment,
commit и push в этом этапе не выполнялись.

Cloudflare использует исключительно серверный REST endpoint модели
`@cf/black-forest-labs/flux-2-klein-4b`. Один подарок вызывает один HTTP-запрос,
в том числе для четырёхпанельного комикса. Нативный `FormData` формирует boundary;
заголовок Content-Type вручную не задаётся. Фото передаётся бинарным
`input_image_0` с нейтральным именем `reference.png`.
Переадресации, автоматические повторы, AI Gateway и переход на другую модель отсутствуют.

- **Caricature:** prompt задаёт профессиональный художественный шарж с выразительными
  чертами и стилизованными пропорциями. При фото запрашивается узнаваемость;
  без фото — вымышленный взрослый персонаж. Товар и его серверное описание входят в prompt.
- **Greeting Card:** AI создаёт иллюстрацию с учётом товара, повода и пожеланий.
  Sharp добавляет имя, повод, пожелания и товар в отдельной области под изображением.
  Имена не нужно отправлять модели. Буквы рисует приложение, не AI.
- **Mini Comic:** один запрос на композицию 2×2, общий персонаж, последовательность
  «выбор → покупка → забавное применение → счастливый итог». Sharp добавляет
  четыре локализованные подписи. Панели сохраняются полностью; место под текст
  добавляется отдельно. Пожелания направляют иллюстрацию, подписи строятся по шаблону.
- **PNG:** строго проверяются REST-конверт, Base64, размер ответа, формат, число кадров
  и разрешение 1024×1024. Допустимые PNG/JPEG/WebP нормализуются в PNG без метаданных.
  После локальных надписей работает прежний DE/EN footer PayPal / Delight AI.
  Итоговые размеры: 1024×1137 для шаржа, 1024×1577 для открытки,
  1024×1425 для комикса. Просмотр и скачивание используют одинаковые сохранённые байты.

Для одинакового текста на Windows/Linux добавлены Noto Sans Regular и лицензия SIL OFL.
Шрифт поставляется с backend; загрузки внешних шрифтов при работе нет.
Новых npm-зависимостей нет. Реальные художественное качество, сходство и точность
композиции требуют отдельной первой генерации; имитация API этого не доказывает.

## Права, стоимость и ошибки

Одна подтверждённая покупка по-прежнему даёт один подарок. Общая блокировка заказа
действует для всех режимов. Повтор POST после успеха возвращает сохранённый результат;
параллельный POST во время работы возвращает GENERATING без нового AI-запроса.
Проверка владельца, платежа и фото выполняется до расхода.

SQLite мигрирует v2/v3 → v4 в транзакции: добавляются `ai_attempts`, отдельная таблица `ai_lab_runs` и индексы.
Существующие строки заказов, прав и изображений не переписываются. В журнале:
ID попытки/заказа, режим, статус, время и зарезервированная оценка Neurons.
Ни prompt, ни фото, ни поля персонализации, ни токены туда не записываются.

Перед внешним вызовом одна SQLite-транзакция проверяет глобальные/сессионные лимиты
и резервирует расход. Это работает и между разными соединениями SQLite, переживает
перезапуск. Все отправленные попытки учитываются, включая ошибки и неопределённость;
автоматического возврата бюджета нет. Оценка для фиксированных 1024×1024:

```text
ceil((4 × 26.05 + (фото ? 5.37 : 0)) × 1.25)
= 131 Neurons без фото / 137 Neurons с фото
```

25% — локальный запас, а не гарантия точности биллинга. Сутки считаются по UTC;
запросы, чья граница обработки пересекает полночь, консервативно учитываются и
в начале следующих суток. Playground и другие приложения этот журнал не видит.
На аккаунте следует сохранить Workers Free и проверять фактический расход в Dashboard.

| Настройка | По умолчанию | Допустимый максимум |
| --- | ---: | ---: |
| `AI_TIMEOUT_MS` | 45000 | 50000 |
| `AI_MAX_CONCURRENT` | 2 | 4 |
| `AI_DAILY_REQUEST_LIMIT` | 50 | 100 |
| `AI_SESSION_DAILY_REQUEST_LIMIT` | 50 | 100 |
| `AI_DAILY_NEURON_LIMIT` | 8000 | 9000 |

Положительные целые значения проверяются при старте. Суточные квоты ограничивают
число AI-запросов, а не число оплаченных покупок; неиспользованное право сохраняется.
При исчерпании возвращается локализованная ошибка, без вызова Cloudflare.

`AI_ENABLED=false` отключает новые внешние генерации после перезапуска процесса.
Mock и просмотр старых результатов продолжают работать. Уже отправленный запрос
нельзя отозвать из Cloudflare или считать гарантированно бесплатным.

Явные HTTP 400/401/403/413/422/429 оставляют право AVAILABLE для новой ручной попытки;
сам провайдер ничего не повторяет. Таймаут, потеря соединения, HTTP 5xx, неизвестный
конверт, невалидное изображение или ошибка обработки/сохранения после отправки
переводят попытку в UNCERTAIN, а публичное состояние подарка — в **REVIEW**.
Право удерживается для проверки, не считается использованным. GET, reload, restart,
переключение режима и возврат к mock не обходят эту защиту.
Истёкшие после аварии STARTED-попытки также переходят в REVIEW.

Приложение логирует только ID заказа, режим, длительность и исход генерации.
Технические HTTP-логи сервера остаются прежними; тела запроса и ответы провайдера
в них не добавляются.

## Проверка неопределённого результата оператором

Нового публичного административного API нет. После проверки исхода и расхода
в Cloudflare оператор может разрешить **последующую ручную** попытку локальным
скриптом. Сначала остановить только этот backend, использовать его фактический
явно заданный `DATABASE_PATH` существующего файла и собранный `server/dist`.
Утилита включается в существующий релизный архив вместе с `server/dist`.
В SSH-сеансе загрузить окружение сервиса безопасно (например, Node.js `--env-file`
с runtime-файлом сервиса); сам systemd не передаёт его интерактивной оболочке.
Не выполнять команды на рабочей БД
без решения владельца конкретного случая.

```powershell
# Показать только технические метаданные попыток заказа:
node server/dist/review-ai-attempt.js ORDER_UUID

# Лишь после отдельного решения: новый запрос может потребовать дополнительных Neurons.
node server/dist/review-ai-attempt.js ORDER_UUID ATTEMPT_UUID --authorise-another-attempt
```

Скрипт проверяет связь заказа и текущей неопределённой попытки, отсутствие готового
подарка, сохраняет журнал и расход. Сам генерацию не запускает. После запуска backend
покупатель явно нажимает создание; автоматического списания нет.
Если результата нет, это не доказательство отсутствия расхода в Cloudflare.

Миграция сохраняет данные, но Stage 4 не поддерживает схему v4. Подготовленный
процесс активации закрывает этот сайт на время миграции и при неудачном health-check
возвращает код, runtime и снимок БД до открытия доступа. Живой VPS не изменялся.
Поздний ручной rollback требует отдельной проверки новых данных.

## Фото, локализация и минимальные дополнения API

Исходное фото необязательно; только для Caricature. Два выключенных по умолчанию
checkbox в Cloudflare-режиме покрывают backend-обработку и отдельно передачу
Cloudflare. Без согласия выбор файла запрещён, сервер также проверяет передачу.
Отзыв согласия удаляет выбор. Фото до 5 MiB / 16 MP проверяется, поворачивается,
очищается от EXIF и других метаданных, уменьшается до максимум 511×511.
Оригинал и очищенные байты обрабатываются только в памяти и очищаются после обработки,
включая ошибки. Исходные фото не записываются в файлы или SQLite.
После перехода в REVIEW браузер также очищает фото и персонализацию: если оператор
разрешит новую попытку, прежнее скрытое фото не отправится повторно.

В Cloudflare передаются товар, описание, язык, повод и пожелания, а также очищенное
фото при согласии. Имена добавляются локально. Готовое PNG может содержать имя,
пожелания или созданное сходство и сохраняется в защищённом хранилище — это явно
указано в Privacy Policy. Сохранённые подарки остаются доступными только владельцу
cookie-сессии. Исходный mock не персонализируется и помечается DEMO.

Нужные расширения существующего API:

- `/api/store`: `gifts.provider`, `gifts.enabled` вместе с прежним `isDemo`.
- Необязательное `photo.cloudflareConsent`; обязательно `true` для фото в Cloudflare.
- `gift.status=REVIEW` и `result.provider=cloudflare`; существующие поля сохранены.
- Локализованные коды ошибок отключения, квот, отказа и необходимости проверки.

В UI статичные примеры помечены SAMPLE / BEISPIEL; настоящий результат не имеет DEMO.
Дизайн и PayPal Checkout не переделывались. DE/EN Privacy Policy и Impressum
обновлены по фактическим потокам; placeholders владельца и юридической проверки
сохранены. Оригинальные фото и готовые результаты имеют разные правила хранения.

## Браузерные испытания — после разрешения deployment

Владелец подтвердил Workers Free. Разработчик готовит сервер существующим
`deploy/publish.ps1 -EnableCloudflareLab`, безопасно переносит credentials и
включает защищённую страницу `/ai-lab`. Владельцу не нужны консольные команды.
Все три режима доступны без новых покупок; тестовые данные отделены от заказов.
Новые попытки запускаются только кнопкой, общий бюджет 50 попыток / 8000 расчётных
Neurons в сутки, одновременно 2. Старое ограничение 1/200 отменено.
По умолчанию локальные и автоматические проверки используют mock/off.

ожидание заменено проверкой корректного уведомления об исходном фото и готовом PNG.
Проверка кода также выявила необходимость очищать выбор фото после REVIEW;
для этого добавлен браузерный регрессионный сценарий.

Скриншоты тестового приложения (не AI-генерация):
`.npm-cache/stage5-<режим>-<en|de>-studio.png` и `-result.png`.
Матрица прежнего интерфейса 375/768/1440 px и DE/EN входит в browser suite;
новые Cloudflare-формы дополнительно проверены на 375 и 1440 px.

Тесты используют отдельные временные SQLite, синтетические имена/изображения и
подменённые транспорты Cloudflare/PayPal. Ни текущие пользовательские заказы,
ни рабочие подарки не используются как тестовые fixtures.
Cloudflare transport проверяет реальную сериализацию multipart и binary photo;
глобальный fetch в его серверном наборе запрещён. Браузер блокирует внешние HTTPS
запросы кроме подменённого SDK. Цветное поле в новых тестовых PNG — намеренный
синтетический ответ API, не результат AI.
